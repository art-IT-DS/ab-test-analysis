# A/B тест: анализ конверсии

## Задача
Проверить, увеличивает ли новая версия страницы конверсию.

## Данные
A/B Testing Dataset (Kaggle). ~294 000 пользователей.
Группы: control (147 202), treatment (147 276).

## Метод
1. Посчитали конверсию в контрольной и тестовой группах.
2. Провели t-тест для сравнения средних.
3. Построили доверительные интервалы.
4. Оценили нужный размер выборки.

## Результат
- Конверсия в control: 12.04%
- Конверсия в treatment: 11.89%
- Разница: −0.15 п.п.
- t-статистика: −1.2369
- p-value: 0.2161
- CI 95% control: [11.87%, 12.21%]
- CI 95% treatment: [11.73%, 12.06%]

## Вывод
Разница статистически НЕ значима (p = 0.2161 > 0.05).
Новая страница не лучше старой. Внедрять не стоит.

## Рекомендации
1. Не внедрять новую страницу.
2. Проверить другие гипотезы (дизайн, кнопка, текст).
3. Увеличить размер эффекта: тестировать более радикальные изменения.
